# Student Placement Navigation Platform

A privacy-first Student Placement Navigation Platform (SPNP) that keeps placement eligibility deterministic, institution-controlled, and auditable. The backend is FastAPI + SQLAlchemy + Alembic (Python 3.11+). The frontend is React + TypeScript + Vite. AI assistance is strictly advisory; all authoritative decisions are computed deterministically from institutional records.

## Architecture (summary)

- **Backend (`backend/`)**: FastAPI app at `app.main:app`, versioned API under `/api/v1`, layered services (`app.services.*`), SQLAlchemy ORM (`app.db.models`), Pydantic schemas, RBAC (`app.core.rbac`), rate limiting via SlowAPI, audit logging (`app.services.audit`), optional AI providers (`app.services.ai_service`) with deterministic fallbacks.
- **Frontend (`frontend/`)**: Vite + React + TypeScript SPA. Admin pages under `pages/admin/*`, student pages under `pages/student/*`, shared components and API client (`api/client.ts`). Uses a lightweight Vite proxy in dev (`/api` → `http://127.0.0.1:8000`).
- **Database**: SQLite by default for local development; production enforces PostgreSQL (`postgresql+psycopg://...`). Migrations via Alembic (`alembic/`), two migrations currently (`264a0e98b34f` initial schema, `3f9a2c4e8b1d` revoked refresh tokens).
- **Security**: JWT access/refresh (refresh rotation + server-side denylist), httpOnly refresh cookie (SameSite=Strict), tenant isolation by `institution_id` on all scoped rows, password policy, RBAC per route, OpenAPI docs exposed only outside production (or when explicitly enabled).

## Setup

### Prerequisites
- Python 3.11+
- Node.js 20+ (tested with Node 24, npm 11)
- Git

## Environment variables

Copy `.env.example` to `.env` in `backend/` and adjust as needed. Defaults are safe for local dev with SQLite.

Key variables (see `backend/.env.example` for the full list):
- `ENVIRONMENT` (`development|test|production`) — controls doc exposure and production guards.
- `SECRET_KEY` — required >=32 chars in production; dev/test have lenient defaults that `ensure_production_safe()` rejects in production.
- `DATABASE_URL` — `sqlite:///./placement.db` by default; PostgreSQL required in production.
- `FIELD_ENCRYPTION_KEY` — Fernet key (urlsafe base64, 32 bytes) required in production.
- `AI_ENABLED`, `AI_PROVIDER` (`heuristic|openai_compatible|anthropic|local`), `AI_API_KEY`, `AI_MODEL`, `AI_BASE_URL` — AI is advisory only; the app falls back to deterministic heuristics on provider failure.
- `SEED_ON_STARTUP` (`false`) — never true in production.
- `SEED_ADMIN_EMAIL`, `SEED_ADMIN_PASSWORD`, `SEED_STUDENT_PASSWORD` — demo credentials for seeding. Unset values generate random passwords printed at seed time.
- CORS, rate limiting, upload/document limits, API docs toggle, pagination, etc.

Production startup calls `settings.ensure_production_safe()` and refuses to boot if configuration is insecure.

## Seeding

Run the seeder from `backend/` with the virtualenv active:

```bash
python -m app.seed  # sensible defaults (24 students)
python -m app.seed --students 40
python -m app.seed --no-applications  # skip applications/resumes
```

The seeder is idempotent and refuses to run when `ENVIRONMENT=production`. If you don't set `SEED_ADMIN_PASSWORD`/`SEED_STUDENT_PASSWORD`, random passwords are printed once at seed time.

## Demo accounts

Default demo emails (generated by seed) follow the example.edu domain:
- Admin: `admin@kletech.example.edu`
- Students: `first.last@student.kletech.example.edu` (e.g., `aarav.sharma@student.kletech.example.edu`)

Use the password(s) printed by the seeder, or set them via `SEED_*` env vars to pin them.

## Running locally

Start the backend (API + docs):
```bash
cd backend
.venv\Scripts\activate
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

Start the frontend (dev server):
```bash
cd frontend
npm run dev
```

Vite proxies `/api` to `http://127.0.0.1:8000`. Access:
- Frontend: http://localhost:5173
- API: http://127.0.0.1:8000
- Swagger UI: http://127.0.0.1:8000/docs
- Redoc: http://127.0.0.1:8000/redoc
- OpenAPI JSON: http://127.0.0.1:8000/openapi.json
